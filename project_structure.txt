Flutter Enterprise Boilerplate — Project Structure
==================================================

Last updated to match the current repository layout (scripts, workflows, flavors, easy_localization).

ARCHITECTURE
------------
Clean Architecture per feature: domain / data / presentation
State: flutter_bloc + Freezed
DI: GetIt + Injectable
Navigation: AutoRoute
Localization: easy_localization (assets/translations/*.json)
Tooling: FVM (fvm flutter / fvm dart) + shell scripts in scripts/

FLAVORS
-------
| Flavor    | Entry point             | Env file       | Android suffix | iOS scheme |
|-----------|-------------------------|----------------|----------------|------------|
| dev       | lib/main_dev.dart       | .env.dev       | .dev           | dev        |
| staging   | lib/main_staging.dart   | .env.staging   | .staging       | staging    |
| prod      | lib/main_prod.dart      | .env.prod      | (none)         | prod       |
